# AGENTS.md

This repository is **MyLife Guide Malaysia**, an English Malaysian reference layer and assistant skill derived from 《高性价比人生指南》. Start at [malaysia/README.md](malaysia/README.md). The original `book/` and `docs/` remain Chinese source material, not localized Malaysian guidance.

- For life questions, use [skills/mylife-guide/SKILL.md](skills/mylife-guide/SKILL.md) and Malaysian references first. Never substitute a China-specific rule for a missing Malaysian rule.
- For Malaysian reference edits, cite current Malaysian primary sources, record access dates, distinguish Peninsular/Labuan, Sabah and Sarawak where relevant, and preserve unresolved questions.
- For original book edits, preserve the evidence and follow the original authoring rules below. Malaysian material belongs in the separate reference layer; do not rewrite original evidence populations or prices as Malaysian facts.

- **改这本书**（增删条目、改正文、动工具脚本）：规则全在 [CLAUDE.md](CLAUDE.md) 里，全部适用，先读完再动手。文件名叫 CLAUDE.md 只是历史原因，内容与工具无关。
- **用这本书回答问题**（有人问该不该做、值不值、怎么选、出事了先做什么、能领哪笔钱、犯不犯法）：按 [skills/mylife-guide/SKILL.md](skills/mylife-guide/SKILL.md) 执行，先查条目再答，答复里注明出自第几节第几条。装到别的目录去用的办法见 [skills/mylife-guide/README.md](skills/mylife-guide/README.md)。
